<objective>
Per CONTEXT.md amendment A-01, thread an optional `endLine` — the block's full source range, emitted by `RenderedMarkdownView.vue` (plan 16-03) via the `activate` event plan 16-04 wires through `DiffWorkspace.vue` — through the `activate-line` workspace event, the `persist-comment`/`reveal-line` workspace commands, and Monaco's own anchor decoration, so a range comment is both submitted with its true range and highlighted across that whole range when revealed in Source view. This depends on plan 16-07's additive, optional `endLine` field on `DurableAnchorV1Schema`/`AddCommentRequestSchema`, and on plan 16-04's `activate` event and host-swap wiring already being in place.

Purpose: closes the A-01 gap left by plan 16-04's toggle/host-swap — a rendered-block comment's full source range must survive the round trip from creation through to Source-view highlighting, not just its first line.

Output: `endLine` flows end to end from `RenderedMarkdownView`'s `activate` event to the `addComment` mutation and back into Monaco's Source-view range decoration; every existing single-line call site keeps behaving identically since `endLine` is optional everywhere it was added.
</objective>
