<objective>
Extend `StatusBadge.vue`'s visually-hidden label with a ", single pane" suffix for added/deleted/type-changed reviewable files (D-09), thread the reviewability signal into its one existing caller (`FileRow.vue`, the file tree) so binary/oversized/unsupported files are correctly excluded (D-08), and replace `ActiveFileToolbar.vue`'s raw `status.kind` text with `<StatusBadge>` plus an exact-copy layout label for single-pane files only (D-10, D-11), using the 13-02 pure functions to decide routing and derive the type-changed "was `<kind>`" text.

Purpose: PANE-03 requires telling single-pane files apart from side-by-side files in BOTH the file header and the file tree, without color. `StatusBadge.vue` is already the one shared, color-independent (tone class + visually-hidden text) status indicator used in the tree; extending its hidden label covers the tree automatically, and reusing it in the header (a component that currently shows no badge at all, only raw text) covers the header the same way.

Output: tree rows and the file header both carry an unambiguous, non-color-dependent single-pane marker for exactly the three qualifying, reviewable statuses — and no other file.
</objective>
