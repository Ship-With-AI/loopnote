<objective>
Prove Phase 14's entire browser-observable contract end to end through the packaged CLI and a real Chromium session: picker-group-equivalent launch (via the non-interactive `--staged`/`--unstaged`/`--worktree` flags D-02 introduces, since no existing Cumpa e2e test in this repository drives the raw interactive `@inquirer/search` TTY picker — every one of them bypasses it, either via the `CUMPA_LAUNCH_OPTIONS` test-only env var for committed sessions or, after this phase, via real non-interactive flags, which exercise the exact same `launchUncommittedSession`/`createUncommittedSessionApp` code the interactive picker converges on per 14-09 Task 2) -> frozen-snapshot display that survives a real out-of-session edit -> Refresh (button and `Alt+Shift+R`) -> `RefreshSummaryPanel` with correct counts -> comment reclassification to stale -> Export-section gating -> terminal `r`-keypress refresh.

Phase 14 has a strictly larger user-facing surface than Phase 13 (new picker group and CLI-flag launch flow, frozen-snapshot display, Refresh button + `Alt+Shift+R` + `r`-keypress, passive change indicator, session banner, `RefreshSummaryPanel`, comment reclassification, export-section gating), yet without this plan none of it is proven through the real browser-rendered, packaged CLI surface this project's own stated contract requires. Output: a new `tests/e2e/uncommitted-review.spec.ts` with two tasks' worth of Playwright tests covering the full chain above.
