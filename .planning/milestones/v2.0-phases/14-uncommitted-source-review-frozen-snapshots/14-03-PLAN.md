<objective>
Add `uncommittedReviewKey(sourceKind, baseCommitOid, firstSnapshotDigest)` to `src/domain/comparison-key.ts`, structurally identical to the file's existing `rangeReviewKey()` framed-field hashing idiom, per RESEARCH.md Required Focus 1 §1.

Purpose: this is the one function that makes WTREE-05 true by construction. The draft/anchor identity for an uncommitted session must derive from the exact frozen content reviewed (`firstSnapshotDigest`, the chain's first entry — never updated by subsequent Refreshes), not from a sentinel "head" value, so two different working-tree states against the same base never share or overwrite a draft.

Output: `uncommittedReviewKey(sourceKind: 'staged' | 'unstaged' | 'worktree', baseCommitOid: string | undefined, firstSnapshotDigest: string): string`, returning a 64-hex-character sha256 hex digest, exported for use by 14-08's session/capability wiring.
