<objective>
Extract the six file-IO primitives that `src/server/patch-snapshot.ts` currently defines as module-private functions (`digest`, `frame`, `isMissing`, `syncDirectory`, `writeOwned`, `boundedFileBytes`) plus the `MAX_SIDE_BYTES` ceiling into a new shared module `src/server/snapshot-fs.ts`, with zero behavioral change. This is pure mechanical extraction, not a rewrite.

Purpose: `src/server/worktree-snapshot.ts` (planned in 14-07) needs the exact same bracket-and-retry file-read discipline `patch-snapshot.ts` already proves in production (`boundedFileBytes`'s stat-then-bounded-read-then-verify shape). RESEARCH.md's Anti-Patterns section explicitly forbids reaching into `patch-snapshot.ts`'s private helpers or copy-pasting them; the sanctioned approach is extracting them into a shared module first, as its own explicit task, before 14-07 builds on top.

Output: `src/server/snapshot-fs.ts` exporting `digest`, `frame`, `isMissing`, `syncDirectory`, `writeOwned`, `boundedFileBytes`, `MAX_SIDE_BYTES`; `patch-snapshot.ts` importing all six from it and no longer defining them locally.
</objective>
