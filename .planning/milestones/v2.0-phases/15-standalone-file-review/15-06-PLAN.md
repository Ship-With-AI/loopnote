## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-15-16 | Elevation of Privilege | `createStandaloneCapabilityRegistry` export capability leaking onto staged/unstaged/worktree sessions | mitigate | Export capability exists only on the object `createStandaloneCapabilityRegistry` returns, which only `createStandaloneSessionApp` ever calls; `createUncommittedSessionApp`/`createUncommittedCapabilityRegistry` are untouched and still omit `exportReview`/`revealExportDirectory`, so `routes.ts`'s 404-guard continues to reject export for those sourceKinds |
| T-15-17 | Repudiation | Export provenance correctness | mitigate | `exportReview`'s standalone scope is built from the same frozen `snapshot.files()`/`snapshot.readContent()` the browser itself reads from — never a second, independently-resolved file list — so the exported `fileDigests` cannot drift from what was actually reviewed |
| T-15-18 | Information Disclosure | `ensureManagedExportsRoot`/`assertManagedExportsRoot` reuse | mitigate | Reused verbatim from the exact-patch registry's already-audited managed-directory discipline; no new directory-construction logic is introduced |
