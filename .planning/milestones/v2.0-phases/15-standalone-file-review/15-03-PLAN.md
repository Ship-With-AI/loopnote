| Boundary | Description |
|----------|--------------|
| Resolution (Plan 15-01, point-in-time) → byte capture (this plan) | A file resolved as matching may be replaced, deleted, or turned into a symlink between `resolveStandaloneArguments` returning and the actual disk read — TOCTOU |
| Captured manifest → disk (`.cumpa/` content-addressed storage) | The manifest and content files are the durable record a later Refresh/export trusts |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-15-09 | Tampering | TOCTOU between `resolveStandaloneArguments`/`classifyStandaloneGitState` and the actual content read inside `captureWorktreeManifest` | mitigate | The standalone branch feeds into the exact same `captureFileWithRetry` (torn-capture retry) and expected-vs-observed re-enumeration pass every other sourceKind already uses; a file that disappears or changes type between resolution and read is marked `'changed-during-capture'` rather than silently captured wrong — zero new code, inherited by construction from reusing `captureWorktreeManifest`'s existing pipeline |
