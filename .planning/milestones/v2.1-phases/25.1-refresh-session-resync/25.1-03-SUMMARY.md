## Deviations from Plan

1. **Necessary production fixes in a nominally test-only plan.** Packaged tests exposed constructor-captured reducer inventory, session-order navigation, and FileTree watcher fallback overriding the parent. Fixed at the shared state/selection boundaries rather than weakening assertions.
2. **Incorrect file-ID premise corrected.** Worktree/unstaged/untracked/standalone IDs are not universally content-derived. ID equality, or only the newest delta, cannot safely gate selected content reload after a partial failure. Explicit Refresh now reloads the current selected snapshot.
3. **Draft-loss prevention completed.** An active-only autosave could miss a composer on another file; inventory pruning then discarded it. Origin-aware saves settle before recapture, failures/pending saves stop it, and busy mutation locks prevent newly typed text racing that preflight.
4. **Plan recipes corrected without reversing prior decisions.** Preserved D-17 autosave and D-18 stable identity; tested existing-thread edits for THREAD-08; used intent-to-add for Unstaged additions. UI-SPEC's badge weight was corrected from 400 to the reused shared component's existing 600, without changing production typography.
