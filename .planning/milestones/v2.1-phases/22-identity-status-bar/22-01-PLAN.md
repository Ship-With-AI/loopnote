<feature>
  <name>Middle-truncation helper for long ref/branch names</name>
  <files>src/domain/truncate-middle.ts, tests/unit/truncate-middle.test.ts</files>
  <behavior>
    - `truncateMiddle('main', 28)` → `'main'` (input shorter than max: unchanged).
    - A string whose length is exactly `max` is returned unchanged — do not add an ellipsis purely because `text.length === max`.
    - A string of length `max + 1` (the smallest input that must truncate) produces a result of exactly length `max` (prefix + `'…'` + suffix === max characters).
    - `truncateMiddle('feature/payments-processing-v2', 20)` → result length ≤ 20, result contains exactly one `'…'`, and the result's leading characters match the input's leading characters (prefix kept) while its trailing characters match the input's trailing characters (suffix kept) — i.e. it is a middle truncation, not `text.slice(0, 19) + '…'`.
    - `max < 1` → `''`. `max === 1` → a single truncated character with no ellipsis (the budget has no room for a separator). Reserve 1 character for the ellipsis otherwise; split the remaining budget between prefix and suffix with `Math.ceil(budget / 2)` for the prefix and `Math.floor(budget / 2)` for the suffix (favors the prefix by one character on odd budgets — more leading context is the useful side for ref names).
    - A string containing an astral-plane emoji (e.g. a worktree path containing `📁`, a surrogate pair) or a combining diacritic must not be split mid-codepoint when truncated: iterate with `Array.from(text)` (codepoint-aware), never slice the raw string by UTF-16 code-unit index, mirroring `path-bytes.ts:24`'s `for (const character of value)` codepoint-safety convention.
  </behavior>
  <implementation>
    Plain exported function, no class, no default export, no side effects — same shape as `path-bytes.ts`'s `controlSafeDisplay` (`export function controlSafeDisplay(value: string): string`). Signature: `export function truncateMiddle(text: string, max = 28): string`. Guard `max < 1` first (return `''`), then `text.length <= max` (return `text` unchanged — use the raw `.length` as a fast path, then re-check with `Array.from(text).length <= max` since UTF-16 code-unit length can exceed codepoint count for astral characters). For `max === 1`, return the single first codepoint via `Array.from(text)[0]`. Otherwise reserve one character of budget for `'…'`, compute `headLen = Math.ceil((max - 1) / 2)` and `tailLen = Math.floor((max - 1) / 2)`, and build the result from `Array.from(text).slice(0, headLen).join('')` + `'…'` + `Array.from(text).slice(-tailLen).join('')` (guard `tailLen === 0` so `.slice(-0)` — which is a no-op slice returning everything — does not leak the whole tail; use `chars.slice(chars.length - tailLen)` instead of `.slice(-tailLen)` to avoid the `-0` pitfall). Do not export or introduce any other helper; this is the single public surface.
  </implementation>
</feature>
