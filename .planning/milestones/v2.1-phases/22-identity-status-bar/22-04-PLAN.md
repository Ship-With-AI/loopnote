Fix every e2e/integration Playwright locator across seven spec files that plan 22-02's `IdentityPill.vue`/`IdentityPopover.vue` markup change breaks — per A11Y-03 ("every spec break this phase's markup changes cause must be fixed in a plan that depends on the breaking change"). Output: All seven spec files below pass against the packaged build with zero assertions referencing any of the deleted classes/text.
