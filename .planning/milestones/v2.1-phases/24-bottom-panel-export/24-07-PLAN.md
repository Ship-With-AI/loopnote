Local disclosure state, session-local per `24-PATTERNS.md`'s "Shared Patterns #3" rule (never lifted to `BottomPanel.vue`/`App.vue`, same precedent as `SummarySection.vue:25`/`ExportSection.vue:44`'s own local `open` refs): `const collapsedByFileId = ref(new Map<string, boolean>());` default expanded (a file group is collapsed only once its `fileId` is explicitly set `true` in this map). `function toggleFileGroup(fileId: string): void` reads the current value (default `false`), writes the opposite via a new `Map` instance (Vue reactivity — never mutate the existing `Map` in place).

Template, when `comments.length === 0`: render only the verbatim empty state `"No comments yet. Hover a line number in the diff and click +."` (exact text, design source) — no tab-bar/header markup change, no grouped list.

Otherwise, for each `group` in `fileGroups.value`: a file-group header row — twistie (`▾`/`▸` text glyph, `aria-hidden="true"`, same convention as `DirectoryRow.vue:85-87`'s `.directory-row__disclosure`), `fileTypeMarkFor(group.leaf.file.newPath?.display ?? group.leaf.file.oldPath?.display)` rendered the same way `FileRow.vue:142` renders its own `fileTypeMark` (colored `<span>` via `:style="{ color: \`var(${mark.tone})\` }"`), a `<PathText :display="..." />` for the name + dim directory (same component `BottomPanel.vue:12`/`:306,308` already imports for this exact purpose), then `group.rows.length` rendered bare (`--font-size-metadata`, no pluralized noun, matching the sketch's bare count) — `role="button"`, `:aria-expanded`, toggling that group's row visibility via `toggleFileGroup(group.leaf.fileId)`.

For each `row` in a non-collapsed group's `rows` (already bucketed/ordered by `comments-tab-groups.ts` — this component does no further sorting): a clickable `<li>` (`role="button"`, `tabindex="0"`, `@click`/`@keydown.enter` both calling `emit('reveal', row.comment.id, group.leaf.fileId, row.comment.side, row.comment.line)`) rendering per the bucket table below, with the icon/text treatment keyed off `row.bucket`:

| Bucket | Icon | Text treatment |
|---|---|---|
| open | `comment` | `--text-primary` |
| stale | `warning` | `--text-primary`, mono side/line in `--status-warning-foreground` |
| resolved | `check` | `--text-muted` (entire row) |

First-comment-line text is `row.comment.body` (ellipsized via CSS, one line — no new truncation JS), right-aligned mono side/line in the compact bare `"B{n}"`/`"H{n}"` format (`row.comment.side === 'base' ? 'B' : 'H'` + `row.comment.line`, no space, no "Head ·" prefix — distinct from the inline thread header's full format per `24-UI-SPEC.md`).

After every live-file group, render `orphanedGroups.value`'s trailing groups: each a non-interactive `<li>` (no `role="button"`, no `@click`, no `tabindex`) per comment, muted text (`--text-muted`), `warning` icon, and a `ReviewStateBadge kind="unavailable" label="Anchor missing" size="compact"` chip in place of a side/line (Phase 23's new `size="compact"` prop, per this plan's cross-phase dependency declaration — reconcile against `ReviewStateBadge.vue`'s real prop list at execution time if it differs).
