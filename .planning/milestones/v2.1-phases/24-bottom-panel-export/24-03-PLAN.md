Add `onBeforeUnmount` to the existing `import { computed, nextTick, ref, watch } from 'vue';` (line 2). Immediately below the existing `watch(() => props.failure, (failed) => { ... });` block (lines 125-127), add the module-scope timer and debounce watcher, following `CopyButton.vue`'s existing `resetTimer`/`onBeforeUnmount` timer-cleanup idiom (lines 15-23, 40) for the lifecycle shape, composed with this file's own `watch(() => props.X, callback)` convention for the reactive trigger (there is no exact debounce-`watch` precedent anywhere in `src/web/` per `24-RESEARCH.md`'s "No Analog Found" section — this is the first one, composed from those two existing idioms, not a new generic `useDebounce()`):

```ts
let autosaveTimer: ReturnType<typeof setTimeout> | undefined;
watch(() => props.modelValue, () => {
  clearTimeout(autosaveTimer);
  if (!unsaved.value || props.pending || props.conflict) return;
  autosaveTimer = setTimeout(() => emit('save'), 800);
});
onBeforeUnmount(() => clearTimeout(autosaveTimer));
```

This guard (`unsaved.value && !props.pending && !props.conflict`) is the exact same condition the existing `onTextareaKeydown`'s Cmd/Ctrl+Enter branch (line 97) already uses, so autosave dispatches the identical `emit('save')` path — same server-authoritative mutation, same conflict/stale-draft handling, zero new client-synthesized state (per `24-CONTEXT.md`).

Change the `status` computed's `'Saving'` string (line 39) to `'Saving…'` (ellipsis added). Do not change `'Conflict — unsaved text retained'` (line 37), `'Save failed'` (line 38), `'Retained after reload — not saved'` (line 40), or `'Saved'`/`'Unsaved'` (line 41) — only the `Saving` branch gains the ellipsis, per `24-CONTEXT.md`'s copy table.
