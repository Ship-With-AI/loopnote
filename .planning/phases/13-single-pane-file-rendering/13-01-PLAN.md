<objective>
Add a plain-Monaco-editor construction path to `src/web/monaco/diff-adapter.ts`, parallel to the existing `PublicMonacoDiffAdapter`/`createMonacoDiffAdapter`, so added/deleted/type-changed files can render in one full-width `monaco.editor.create()` pane instead of `createDiffEditor`'s side-by-side layout (D-01). The new adapter reuses the diff adapter's per-editor comment-anchor wiring pattern (cursor capture, mouse-affordance capture, selection decorations, Alt+Enter add-comment action) collapsed to a single fixed `DiffSide`, and rebuilds the comment view-zone logic unpaired — one `IViewZone` on one editor, with no counterpart editor/model/spacer zone (D-01, D-13).

Purpose: PANE-01 and PANE-02 both require a reviewer to comment on any line of a single full-width pane. The existing `rebuildAnchoredLayout` (diff-adapter.ts:509-553) is hard-wired to a paired original/modified editor relationship that does not exist for a single-pane file; porting it unmodified would force a fake counterpart editor into existence. This plan writes the unpaired equivalent instead.

Output: `createMonacoSinglePaneAdapter(host, languageForPath, onChange, side): MonacoDiffAdapter`, usable interchangeably with `createMonacoDiffAdapter` from any caller that only depends on the shared `MonacoDiffAdapter` interface (DiffWorkspace.vue, wired in 13-03).
</objective>
