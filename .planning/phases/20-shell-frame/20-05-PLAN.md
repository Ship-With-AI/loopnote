Internally: `onPointerdown` captures the starting pointer coordinate (`clientX` for `axis === 'vertical'` sash orientation resizing a width, `clientY` for `axis === 'horizontal'` resizing a height — note: UI-SPEC's `aria-orientation="vertical"` describes the SASH's own visual orientation, which resizes a horizontal dimension (width); the panel sash is `aria-orientation="horizontal"` and resizes a vertical dimension (height) — map `axis` to `'vertical'` meaning "sash is a vertical bar, drags along X" for the sidebar, `'horizontal'` meaning "sash is a horizontal bar, drags along Y" for the panel, matching UI-SPEC's own aria-orientation values exactly), calls `event.currentTarget.setPointerCapture(event.pointerId)`, sets `isDragging.value = true`, and registers `pointermove`/`pointerup` listeners on that target. `pointermove` computes `delta = currentCoordinate - startCoordinate`, calls the exported `clampAxisValue(startValue + delta, options.min, options.max)`, and writes it directly to `options.value.value` (live visual feedback during drag, not debounced). `pointerup` releases capture, removes the listeners, sets `isDragging.value = false`, and calls `options.onCommit(options.value.value)` (this is where 20-07's `App.vue` wiring debounces the `panel-state.ts` `.persist()` call — `useSash` itself does not touch `localStorage`). Also expose a `reset(): void` function that sets `options.value.value = options.default` and immediately calls `options.onCommit(options.default)`, for the double-click handler.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Pointer events → inline CSS width/height | `useSash`'s drag math writes a computed pixel value into reactive state and an inline style; the value is always the output of `clampAxisValue`, never raw unclamped pointer coordinates. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-20-06 | Denial of Service (local) | `useSash.ts` clamp math | mitigate | Every write to the live width/height value passes through `clampAxisValue(value, min, max)` before reaching the DOM — an adversarial or buggy pointer event sequence (huge delta, negative delta) can never produce a zero/negative/unbounded layout dimension. |
| T-20-07 | Elevation of Privilege (focus trapping) | `WorkbenchShell.vue`'s relocated `#changed-files` Teleport host | mitigate | Host stays `v-show`, never `v-if` (hard constraint #6) — a `v-if` host would strand the Teleported `FileTree`'s already-mounted roving-tabindex item outside the DOM on next toggle, leaving keyboard focus unrecoverable; `v-show` only toggles CSS `display`, DOM/focus targets stay addressable. |

</threat_model>
