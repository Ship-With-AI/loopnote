<objective>
Add the non-interactive CLI flags `--staged`, `--unstaged`, `--worktree`, `--base <ref|worktree>` to `src/cli/run.ts`'s `Command()` chain (D-02), validate their mutual exclusivity and the D-05 `--base`+`--unstaged` conflict before any Git call, and wire both the flag path and the interactive picker path (14-06's `pickSource()`) to a new `launchUncommittedSession` function that resolves the chosen source into an `UncommittedScope` and calls `createUncommittedSessionApp` (14-08). Purpose: WTREE-01 requires both the interactive picker and non-interactive flags to offer Staged/Unstaged/Working tree; this plan is where both paths converge into one actual launch.

Output: `--staged`/`--unstaged`/`--worktree`/`--base` Commander options, `launchUncommittedSession(selection, dependencies)`, mutual-exclusivity validation producing the UI-SPEC's exact error copy, `r`-keypress wiring, and D-19 recovery-offer wiring at launch time.
</objective>
