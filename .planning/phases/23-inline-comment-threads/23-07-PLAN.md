<objective>
Replace `DiffWorkspace.vue`'s single read-only `h()` literal (today's one-accepted-comment-at-a-time rendering) with a keyed, diff-driven loop that mounts one `CommentThread.vue` per live comment id into Plan 23-05's new per-id adapter nodes — never tearing down and rebuilding every thread on a reactive update (THREAD-08's exact concern). Update every existing Playwright locator this restructuring breaks, in this same plan.

Purpose: this is the consumer half of RESEARCH.md Pattern 3 (diff-by-comment-id reconciliation) — the adapter (23-05) only creates/removes DOM containers by id; this plan decides WHICH ids to create/remove/keep on every `comments` prop change (including a Refresh-driven reconciliation pass) and owns the actual Vue mounting.
Output: `DiffWorkspace.vue` renders N independent threads; every broken locator in the listed spec files is fixed in this commit.
</objective>
