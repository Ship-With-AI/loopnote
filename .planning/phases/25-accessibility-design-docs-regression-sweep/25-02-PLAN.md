## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-25-03 | Tampering / Injection | `handleFilterResult`'s `` `No changed files match "${query}".` `` message | mitigate | The live-region sink uses Vue's default text interpolation (`{{ liveMessage }}`), never `v-html`; Vue auto-escapes interpolated text, so arbitrary filter input cannot inject markup. No new sink is introduced — this reuses the existing `announce()`/`liveMessage` pipeline every other call site already shares. |
| T-25-04 | Denial of Service (debounce timer leak) | `FileTree.vue`'s new `filterAnnounceTimer` | mitigate | Timer is cleared on every `query` change before a new one is scheduled, matching the standard debounce-clear pattern; no unbounded timer accumulation possible. |
| T-25-05 | Information Disclosure | `handleFilterResult`'s announced counts | accept | Matched/total file counts and the typed query text are already visible on-screen in the filter input and the "N of M" badge before the announcement fires; the live region only restates already-visible local state. |
| T-25-SC | Tampering | npm/pip/cargo installs | accept | No new package installs in this plan — zero dependency surface added. |
