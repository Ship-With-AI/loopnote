```ts
async function copyAgentPrompt(): Promise<void> {
  copyMessage.value = '';
  try {
    await navigator.clipboard.writeText(
      `Apply the review in \`${receipt.files[0].path}\` (human-readable: \`review.md\`). `
      + 'Address every open comment; leave resolved ones as context.',
    );
    copyMessage.value = 'Copied agent prompt.';
  } catch {
    copyMessage.value = 'Could not copy. Select the value and copy it manually.';
  }
}
```

`receipt.files[0].path` is the real, already-published `review.json` path (e.g. `.loopnote/exports/<timestamp>/review.json`) — repo-relative, server-returned, already visible to the user via the existing "Copy all receipt details" button on this same receipt (`receiptDetails` computed, line 81) — clipboard-only, nothing sent anywhere, matching `24-CONTEXT.md`'s locked phrasing verbatim (the `<timestamp>` placeholder in CONTEXT's prose is satisfied by this real data, not a literal template string).
